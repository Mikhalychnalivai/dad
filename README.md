# TelescopeControl

Настольное приложение на JavaFX для управления мини-телескопом через Arduino UNO.

## Технологии

- Java 21
- JavaFX 21.0.2
- Maven
- jSerialComm 2.10.4

## Запуск

### Способ 1 — IntelliJ IDEA (рекомендуется)

1. Откройте папку проекта через **File → Open**
2. Дождитесь индексации и загрузки зависимостей Maven
3. Откройте `src/main/java/com/telescope/Main.java`
4. Нажмите **▶ Run** или **Shift+F10**

### Способ 2 — скрипт Windows

`run.bat` и `run.ps1` больше не содержат путей к компьютеру конкретного пользователя. Они используют `JAVA_HOME` или Java из `PATH`, а проект определяют относительно расположения самого скрипта.

Для запуска требуется установленный JDK 21 и Maven в `PATH`. Если Maven не установлен глобально, откройте проект в IntelliJ IDEA и запустите `javafx:run` через встроенную панель Maven.

### Способ 3 — Maven в терминале

```bash
# Если mvn доступен глобально:
mvn javafx:run

# Или через IntelliJ IDEA Maven:
# Maven панель → Plugins → javafx → javafx:run
```

### Способ 4 — VS Code

1. Установите расширение **Extension Pack for Java**
2. Откройте папку проекта
3. Дождитесь загрузки зависимостей
4. Откройте `Main.java` и нажмите **Run**

## Структура проекта

```
src/main/java/com/telescope/
├── Main.java                          # Точка входа, запуск JavaFX
├── controller/
│   ├── MainController.java            # Главный UI-контроллер (привязка FXML)
│   └── TelescopeController.java       # Логика движения, удержание кнопок
├── arduino/
│   └── ArduinoManager.java            # Подключение к Arduino (jSerialComm)
├── model/
│   ├── CoordinateManager.java         # Координаты телескопа (AZ/ALT/RA/DEC)
│   └── CommandLogger.java             # Журнал команд и сообщений
└── ui/
    └── StarMapCanvas.java             # Анимированная карта звёздного неба

src/main/resources/com/telescope/
├── main.fxml                          # Разметка интерфейса
└── styles.css                         # Тёмная космическая тема
```

## Подключение Arduino

1. Подключите Arduino UNO к USB
2. Запустите приложение
3. В верхней панели выберите COM-порт из списка
4. Нажмите **Подключить**

Если Arduino недоступна — приложение работает в **демо-режиме**: команды выполняются локально, координаты обновляются визуально.

## Протокол команд (Serial, 9600 бод)

| Команда     | Действие                          |
|-------------|-----------------------------------|
| `RIGHT`     | Вращение вправо (двигатель 1)     |
| `LEFT`      | Вращение влево (двигатель 1)      |
| `UP`        | Поворот вверх (двигатель 2)       |
| `DOWN`      | Поворот вниз (двигатель 2)        |
| `STOP`      | Остановка обоих двигателей        |
| `SPEED1:50` | Скорость двигателя 1 (0–100)     |
| `SPEED2:75` | Скорость двигателя 2 (0–100)     |

## Возможности

- Тёмная космическая тема
- Управление телескопом кнопками с удержанием
- Регуляторы скорости для каждого двигателя
- Анимированная карта звёздного неба с созвездиями и прицелом
- Отображение координат: AZ, ALT, RA, DEC
- Журнал всех команд
- Демо-режим без Arduino


## Важно при первом запуске на другом компьютере

- Не запускайте проект прямо из ZIP. Сначала полностью распакуйте архив.
- В IntelliJ IDEA выбирайте **папку `JavaFX-приложение`**, внутри которой лежит `pom.xml`, через **File → Open**.
- В настройках проекта выберите JDK 21: **File → Project Structure → Project SDK**.
- Дождитесь, пока IntelliJ импортирует Maven-зависимости.
- Для запуска используйте Maven → Plugins → javafx → `javafx:run` либо кнопку запуска в `Main.java`.
- Скрипты не привязаны к `C:\Users\User` и к старому пути JDK с исходного компьютера.
